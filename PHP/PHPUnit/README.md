# PHP Unit Testing Module

This module demonstrates Test-Driven Development (TDD) basics using the PHPUnit framework.

## Project: E-commerce Price Calculator

A realistic simulation of an e-commerce logic calculator that handles taxes and discounts.

### Key Concepts Covered:
1. **PHPUnit Setup**: Configuration using Composer.
2. **Assertions**: Validating expected outcomes (`assertEquals`, `assertTrue`).
3. **Setup Methods**: Using `setUp()` to initialize objects before tests.
4. **Exception Testing**: Ensuring invalid inputs (like negative prices) throw appropriate exceptions.

### How to Run Tests
Navigate to this directory in your terminal and run:
```bash
./vendor/bin/phpunit tests/PriceCalculatorTest.php
```
