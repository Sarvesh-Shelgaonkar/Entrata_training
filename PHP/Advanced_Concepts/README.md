# Advanced PHP Concepts Module

This module demonstrates advanced object-oriented programming and architectural patterns in PHP.

## Project: User Management API Simulator

A simulated backend API endpoint that validates user registration requests and returns structured JSON responses.

### Key Concepts Covered:
1. **Namespaces & PSR-4 Autoloading**: Organized codebase using Composer's autoloader.
2. **Magic Methods**: Utilizing `__get`, `__set`, and `__toString` for dynamic property handling.
3. **Regular Expressions (RegEx)**: Implementing complex patterns for email and username validation.
4. **API Structure**: Managing HTTP headers and sending JSON responses.

### How to Run
Navigate to this directory in your terminal, regenerate the autoloader, and run the script:
```bash
composer dump-autoload
php index.php
```
